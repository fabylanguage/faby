# Faby for VS Code

Syntax highlighting for [Faby](https://faby.codes) — the AI-native programming language.

- Highlights flows, pipelines (`|>`), `match`, contracts (`expect`/`ensure`), recovery (`?`), `spawn`/`await`, intent blocks, semantic types and string interpolation
- `.fy` file association, `--` line comments, bracket matching

## Install
- From the Marketplace: search "Faby" (publisher: fabycode)
- From file: `code --install-extension faby-0.1.0.vsix`

Run your code with the CLI: `npm i -g @fabycode/cli` · docs at [faby.codes/docs](https://faby.codes/docs)
